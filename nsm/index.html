The site owner needs to connect a free Firebase project before people can create accounts:

  1. Create a project at console.firebase.google.com.
  2. Turn on Authentication › Email/Password.
  3. Create a Firestore Database and paste the rules from nsm/firestore.rules.
  4. Add a Web app and paste its config into nsm/firebase-config.js.

Full steps are in nsm/README.md. Meanwhile you can try the offline demo.
